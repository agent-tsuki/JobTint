# Privacy Policy for JobTint

**Effective Date:** May 2026

## Introduction

JobTint is a Chrome extension designed to help job seekers manage their LinkedIn job applications by color-coding job listings and tracking application status.

This Privacy Policy explains what information JobTint uses, how it is used, and how user privacy is protected.

By using JobTint, you agree to this Privacy Policy.

---

## What JobTint Does

JobTint helps users:

- Identify job application status directly on LinkedIn
- Avoid re-applying to the same jobs
- Track applied jobs using a built-in job tracker
- Export job application history to CSV format

Job status colors:

- 🟢 Green = Not Applied
- 🔴 Red = Applied
- 🟡 Yellow = External Application

---

## Data We Access

JobTint may access limited website content from LinkedIn job pages, including:

- Company name
- Job title
- Job posting details
- Application method (Quick Apply / External)
- Application status
- Date of application

This information is used only to provide the extension’s core functionality.

---

## Data Storage

JobTint uses Chrome local storage (`chrome.storage.local`) to save job tracking information on the user's device.

Stored data may include:

- Company name
- Role title
- Application status
- Date applied
- Application mode
- Notes (if added by the user)

This data remains stored locally in the browser unless the user removes it.

---

## What We Do NOT Collect

JobTint does **not** collect, store, or transmit:

- Passwords
- Login credentials
- Email addresses
- Payment information
- Financial data
- Health information
- Personal messages
- GPS location
- Browsing history outside LinkedIn job pages

---

## Data Sharing

JobTint does **not** sell, rent, or transfer user data to third parties.

User data is not shared with advertisers, analytics providers, or external services.

All processing is performed locally inside the browser unless explicitly stated otherwise.

---

## Remote Code

JobTint does not use remote code.

All JavaScript and functionality are included inside the extension package submitted to the Chrome Web Store.

No external scripts are loaded from third-party servers.

---

## Permissions Used

### Storage Permission

Used to save job application tracking data locally.

### Host Permission (LinkedIn)

Used only on LinkedIn job pages to detect job listings and apply color coding.

JobTint does not access unrelated websites.

---

## CSV Export

Users may export their tracked job applications as a CSV file.

This export is created locally and downloaded directly by the user.

No exported data is sent to external servers.
